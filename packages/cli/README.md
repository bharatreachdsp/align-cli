# @align-agent/cli

The `align` command: captures the decisions made in your Claude Code, Cursor and Codex sessions in a
repository you opt in, and serves your team's confirmed decisions back to your agents.

```sh
npx @align-agent/cli init
```

`init` signs you in with a device code, connects the repository, shows exactly what is captured and asks
before anything is. `align status` shows what is captured and where; `align off` stops it at once.

Requires Node 22.14 or later on macOS or Linux (Windows through WSL). MIT licence.
